# Security policy

Report suspected vulnerabilities through GitHub private vulnerability
reporting when available. Do not put credentials, private evidence, real
decision records, or personal data in a public issue.

In scope:

- future-information or vintage bypass;
- rule-digest or approval bypass;
- path traversal, symlink, HTML, CSV, or artifact-integrity defects;
- public secret or PII leakage;
- unsafe release behavior.

Out of scope:

- the truth of user-supplied evidence;
- security of an external decision system;
- legal or professional advice;
- production controls not implemented by this repository.
