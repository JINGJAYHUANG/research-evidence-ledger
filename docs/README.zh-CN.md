# Research Evidence Ledger｜中文说明

这是一个**决策时点证据冻结、规则回放、结果复盘与学习闭环系统**。

它不是普通的“决策日记”，也不只是来源清单。它要回答：

```text
当时究竟知道什么？
使用的是哪个数据版本？
哪些是事实、推断、情景和预测？
哪些假设可能被证伪？
候选方案如何比较？
决策规则是否在结果出现前锁定？
审批是否完整？
后来结果好，是过程好还是运气好？
新证据究竟改变了判断，还是后来修改了规则？
```

## 核心流程

```text
证据来源与版本
→ 主张与边界
→ 假设与反证条件
→ 预测与区间
→ 方案与情景评估
→ 锁定规则
→ 决策时点快照
→ 确定性回放
→ 结果与后悔值
→ 前瞻性规则改进
```

## 四象限复盘

| 决策过程 | 结果 | 分类 |
|---|---|---|
| 好 | 好 | 决策合理且结果有利 |
| 好 | 差 | 决策合理但运气不利 |
| 差 | 好 | 结果幸运但过程脆弱 |
| 差 | 差 | 过程与结果均需改进 |

工具不会因为结果好，就倒推当时决策一定正确；也不会因为结果差，
就假定当时决策一定错误。

## 重要边界

- 所有案例完全虚构；
- 不包含个人资料、真实业务、账户、客户或凭据；
- 不执行外部动作；
- 哈希链只能帮助发现记录修改，不能证明事实、作者身份或真实发生；
- 评分只评价记录完整性和过程纪律，不认证真实决策质量；
- 新规则只能面向未来，不能重写历史。
