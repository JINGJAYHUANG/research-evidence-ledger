# Limitations

The project validates internal consistency of declared synthetic records. It
does not establish:

- truth or completeness of evidence;
- trustworthy external timestamps;
- legal permission to use a real source;
- correctness of option scores or probabilities;
- absence of omitted options;
- causal effects;
- informed human approval;
- real-world execution or outcome occurrence;
- production safety.

The finite option set and decision rule are supplied by the case author. A
carefully fabricated record can still pass internal checks. Independent review,
real source retention, access controls, and domain-specific governance remain
necessary.
