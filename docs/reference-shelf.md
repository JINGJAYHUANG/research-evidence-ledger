# Public reference shelf

The project uses the following public work as conceptual reference metadata:

- W3C PROV-O and the broader PROV family for interoperable provenance concepts;
- NIST AI Risk Management Framework and its Govern, Map, Measure, Manage lifecycle;
- SLSA provenance concepts for source/build traceability;
- Datasheets for Datasets for structured documentation of data motivation,
  composition, collection, uses, and limitations.

The repository does not redistribute those standards, claim conformance, or
imply endorsement. Current versions and applicability must be checked at their
official sources before adoption.
