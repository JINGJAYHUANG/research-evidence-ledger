# Learning loop

A useful review asks:

1. What surprised us?
2. Which assumption moved outside its declared range?
3. Which forecast was miscalibrated?
4. Did later evidence change the option ranking under the original rule?
5. Did a prospective rule change alter the ranking?
6. Which monitor, threshold, or data source should change next time?
7. Who owns the action and when is it due?

Rule changes are prospective. The original snapshot, rule digest, and recorded
rationale remain immutable evidence.
