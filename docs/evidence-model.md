# Evidence model

## Source fields

Every source records identity, lineage, version, publication time, observation
time, optional effective time, publisher, independence group, authority,
access class, license, summary, and canonical content hash.

## Claim fields

A claim records statement, type, certainty, consequence, scope, whether it was
used for the decision, supporting and conflicting sources, and what is not
proven.

## Independence

Multiple pages controlled by one publisher are one evidence family unless a
stronger independence argument is explicitly documented. Page count is not
corroboration count.

## Provenance claim boundary

A source hash proves only that the stored source metadata has not changed
relative to that hash. It does not prove that the source is true, complete,
legally usable, or accurately interpreted.
