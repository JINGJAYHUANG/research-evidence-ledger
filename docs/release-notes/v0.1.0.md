## Research Evidence Ledger v0.1.0

The first release provides a dependency-free point-in-time evidence and
decision replay reference implementation.

### Included

- source-vintage, claim, assumption, forecast, option, rule, decision, outcome,
  and review contracts;
- deterministic freezing and replay;
- process-versus-outcome review;
- evidence/rule change attribution;
- eight hard gates and seven adversarial mutants;
- hash-chain audit and unsigned Merkle checkpoint;
- three synthetic cases and a static Decision Time Machine Lab;
- fourteen schemas, CLI, tests, Python 3.11–3.13 CI, reproducible Wheel, and
  release provenance.

### Boundary

All examples are fictional and synthetic. This release does not certify factual
correctness, external action, legal compliance, or production safety.
